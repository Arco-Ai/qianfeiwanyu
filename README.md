# 千肥万鱼 · 桌面观察台

一个本地优先的桌面观察台：内置**成熟鲸鱼娘 / Q版鲸鱼娘**两种形态（默认成熟鲸鱼娘），立绘会按时段与心情切换表情，可以戳一戳互动、看每日日程、写日记、聊天，还能接本地 DSH 和 GPT-SoVITS 语音。所有数据默认只存在本文件夹里，不联网。

## 角色形态

在「设置 → 角色 → 角色形态」里二选一，随时切换，各自有独立的全身立绘、表情集与半身通话窗（只显示上半身居中）：

- **成熟鲸鱼娘**（默认）：全身立绘 + 表情差分，通话框用成熟半身像。
- **Q版鲸鱼娘**：软萌 Q 版，全套表情差分，通话框用 Q 版半身像。

两种形态共用同一套场景库背景（按时段 / 季节自动轮换），不另外使用鲸鱼娘专属壁纸。

## 游戏模式（打游戏时省资源）

顶栏有「**游戏模式**」按钮，点一下进入低占用状态，再点「退出游戏」恢复。快捷键 `Ctrl/⌘ + G`，设置 → 玩法里也有开关。状态存在浏览器本地，下次打开仍是上次的选择。

游戏模式只留下**静态立绘、场景背景、时钟、当前台词和切换按钮**，其余全部停掉：

- 停掉全部后台轮询（每 8 秒观察数据、每分钟场景/背景、每 2 分钟日程、天气、日记检查）；
- 停掉打字机逐字动画、CSS 呼吸/漂浮/闪烁动画、毛玻璃与阴影滤镜；
- 停掉 BGM、环境音、音效、自动朗读与语音合成；
- 停掉戳一戳、思考气泡、章节卡、转场特效，收起聊天输入与工具栏。

适合挂机打游戏：画面还在，但不让 GPU 反复合成动画，也不让 CPU 来回读文件。聊天、设置等功能退出游戏模式后照常用。

## 一、快速开始（三种方式，任选其一）

### 方式 A：独立桌面版（推荐，零依赖）

1. 到本仓库 [Releases 页面](https://github.com/Arco-Ai/qianfeiwanyu/releases/latest) 下载最新的 `qianfeiwanyu-v1.0.1-win-x64.zip`（约 245 MB）。
2. 解压后进入 `千肥万鱼/` 文件夹，双击 `千肥万鱼.exe`。

不需要安装 Node.js、不需要浏览器、不需要 `npm install`。整个 `千肥万鱼` 文件夹可以拷到任何 Windows 电脑上直接用。

> 仓库源码本身不含打包产物（`.gitignore` 已忽略 `dist/`）；独立 exe 统一在 Releases 提供。想自己打包时，先 `npm install`，再执行 `node desktop/build-portable.js`。

### 方式 B：源码模式（需要 Node.js 18+）

在仓库根目录（包含 `server.js` 的那一层）执行：

```bash
node server.js
```

然后浏览器打开 `http://127.0.0.1:18765/`。Windows 用户也可直接双击 `start.cmd`。

> 源码模式的后端只用 Node 内置模块，**无需 npm install**。只有想自己打包 exe 时才需要 Electron（`npm install`）。

### 方式 C：作为 DSH 插件使用（可选联动）

仓库里的 `dsh-plugin/` 是一个标准的 DSH Bundle 插件 **`dsh-qianfeiwanyu`**。装进 DeepSeek Harness（DSH）后，她会**跟着 Agent 的工作状态实时换表情、说应景台词**——你写代码她在旁边认真盯着，你忙完她欢呼，你出错她被吓一跳。

| Agent 在做什么 | 她的反应 |
| --- | --- |
| 开始一轮 / 工具执行中 | 认真表情 + 「开始干活了」「调用工具 xxx」 |
| 收到新消息 / 等待 | 疑惑表情 + 「好像有新消息」 |
| 一轮完成 / 告一段落 | 欢呼表情 + 「这轮忙完了」 |
| 出错 | 受惊表情 + 「出错了」 |

**隐私与安全**：插件只监听 Agent 的**状态事件**，不读写会话内容、不联网；状态经 `127.0.0.1` 回环推给本机观察台。观察台开启「游戏模式」时会自动静默，不打扰你打游戏。

**三步上手**：

```bash
# 1. 先让「千肥万鱼」客户端保持运行（默认监听 127.0.0.1:18765）

# 2. 把插件装进 DSH（路径换成你 clone 后的实际位置），装完重启 DSH
dsh plugin --profile desktop add ./dsh-plugin

# 3. 观察台里打开开关：设置 → 对话 → DSH 插件联动
```

验证插件是否活着：浏览器访问 `http://127.0.0.1:3080/dsh-qianfeiwanyu/status`，看到 `{"ok":true,...}` 即正常。

完整说明（配置项、卸载、常见问题、状态调试）见 **[`dsh-plugin/README.md`](dsh-plugin/README.md)**。

## 二、换电脑 / 拷给别人

- **独立版**：把从 Releases 下载并解压后的 `千肥万鱼/` 文件夹整个拷过去即可。设置、素材、日程、日记都写在文件夹内部，跟着走。
- **源码版**：把整个仓库文件夹拷过去，有 Node 18+ 就能跑。
- 端口默认 `18765`。若被占用，桌面版会自动换一个端口；源码版可设环境变量 `FISH_WATCH_PORT=18766` 指定。

### 可选：连接别的电脑上的 DSH

打开「设置 → 对话」，把「DSH 地址」改成对方的移动桥地址，例如 `http://192.168.1.20:3080/m/api`，填好口令后点「测试连接」。

- 没装 DSH 也完全不影响运行：只是聊天功能不可用，观察台的立绘、日程、互动照常工作。
- 也可以设置环境变量 `DSH_ROOT` 指向 DSH 数据目录。

### 可选：本地语音 GPT-SoVITS

- 没装也能正常用，只是不朗读（默认使用浏览器自带语音）。
- 装了的话会自动探测常见安装位置；也可设环境变量 `FISH_SOVITS_DIR` 指向安装目录。

## 三、数据放在哪里

| 内容    | 位置                |
| ----- | ----------------- |
| 设置    | `settings.json`   |
| 素材清单  | `assets.json`     |
| 上传的立绘 | `assets/uploads/` |

程序只读取 DSH 目录（默认 `%USERPROFILE%\.dsh`），不会改动它，除非你手动点「保存到 DSH」。

## 四、发布前请确认

分发给他人前，建议保持以下出厂状态（本仓库已处理好）：

- `settings.json` 中称呼、`portrait`、`dshSessionId`、API 密钥均为空。
- `chat-log.json` 为 `[]`（不含你的私人聊天记录）。
- 不含你的 DSH 会话 ID、SoVITS 参考音频路径等本机信息。

每位使用者第一次打开后，可在「设置」里填自己的称呼、DSH 地址和密钥。这些个人数据都保存在本地，不会上传。

## 五、常见问题

- **没有声音？** 打开「设置 → 音量」集中调整各类声音的开关与大小（语音、音乐/BGM、环境音、音效），拖动即时生效；BGM / 环境音 / 音效的开关也都在这同一页。也可以直接把鼠标移到右下工具栏的**喇叭图标**上，弹出的快捷音量条可随手调这四路音量。
- **想安静欣赏立绘和背景？** 点对话框右侧的小 **×** 进入「纯欣赏模式」——所有界面（顶栏、工具栏、对话框、任务栏、输入抽屉）全部隐藏，背景与立绘完整入镜。点右上角「退出欣赏」、按 `Esc`、或点画面空白处即可退出。
- **能换盘符 / 换用户名吗？** 可以。所有路径都相对程序目录解析，不写死任何电脑路径。
- **需要联网吗？** 日常使用不需要。只有在你主动点「生成立绘」「朗读」并配置了对应密钥时才会发起外部请求。

## 六、素材署名

- **鲸鱼娘素材**：来自 [AATINF/deepseek-whale-girl-assets](https://github.com/AATINF/deepseek-whale-girl-assets)（二创扩展包，AI 生成），已抠成透明底 PNG 存于 `assets/whale/`（无损母版 WebP 备份在 `assets/whale-src/`，不随程序发布）。角色参考 [TreapGoGo/deepseek-whale-girl](https://github.com/TreapGoGo/deepseek-whale-girl)（MIT License, Copyright (c) 2026 TreapGoGo）。再分发请保留此署名，并如实标注使用了生成式 AI 辅助。
- **背景音乐（BGM）**：`assets/audio/bgm/` 下的音乐为**原创程序化合成**（和弦进行 + 分解琶音 + 低音 + pad + 卷积混响，按早晨/白天/黄昏/夜晚/温暖/忧伤配不同调式与节奏），不采样、不引用任何现有曲目旋律，可自由再分发。生成脚本见仓库根目录 `gen_bgm.py`。
- **环境音 / 音效**：`assets/audio/amb/`、`assets/audio/sfx/` 由本地噪声合成，无第三方版权问题。
- **其他角色立绘**：未随本仓库提供；如需自行导入，请遵守对应原作者的授权，勿违规再分发。

## 七、仓库版（纯净模式）说明

本副本为**上传仓库专用**的纯净版本，与本地自用版的区别：

- **不含任何个人信息**：`settings.json` 为空白出厂模板（称呼、API Key、DSH 口令全空），`chat-log.json` 为 `[]`，无日记 / 日程 / 聊天记录 / 绝对路径 / 主机名。
- **不含运行数据**：`data/` 下各目录为空（保留 `.gitkeep`），由使用者运行时自行生成。
- **不含打包产物与依赖**：`dist/`、`node_modules/` 未包含；需要独立 exe 时在本机执行 `node desktop/build-portable.js` 生成。
- **未包含第三方受限素材**：默认只提供成熟 / Q版两种鲸鱼娘立绘，BGM 与环境音均为原创/本地合成，无其他角色的内置立绘或商业游戏素材。
- **游戏模式**：点顶栏「游戏模式」或按 `Ctrl/⌘+G` 进入低占用状态，再按一次退出。

如需提交前二次确认，执行：

```
git check-ignore -v data/diaries/2026-01-01.json dist/千肥万鱼/千肥万鱼.exe
```

应看到运行数据、dist 被忽略；`settings.json` 保持空白即可提交。
