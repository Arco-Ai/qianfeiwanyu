# 千肥万鱼 · 桌面观察台

一个本地优先的桌面观察台：内置**成熟鲸鱼娘 / Q版鲸鱼娘**两种形态（默认成熟鲸鱼娘），立绘会按时段与心情切换表情，可以戳一戳互动、看每日日程、写日记、聊天，聊天可接本地 DSH 会话或 DeepSeek 等第三方对话模型，语音可接 GPT-SoVITS / 飞鱼声线。所有数据默认只存在本文件夹里、默认不联网；只有你主动配置并使用第三方接口时才会发起外部请求。

初衷就是想做一个能把养鱼当成GALGAME玩的一个界面，慢慢地往里边塞了很多功能。当然默认是大肥鱼的形象，如果有需要各位gal玩家可以自行上传角色、背景、音乐等素材，结合人格卡把自己最想对话的那个TA带到身边（弥补各种遗憾？）。希望大家能通过这个工具感受到自由的对话。如果各位有想要添加的功能可以自行使用AI添加，有好点子也可以分享一下。祝大家玩得开心~

## 角色形态

在「设置 → 角色 → 角色形态」里二选一，随时切换，各自有独立的全身立绘、表情集与半身通话窗（只显示上半身居中）：

- **成熟鲸鱼娘**（默认）：全身立绘 + 表情差分，通话框用成熟半身像。
- **Q版鲸鱼娘**：软萌 Q 版，全套表情差分，通话框用 Q 版半身像。

两种形态共用同一套场景库背景（按时段 / 季节自动轮换），不另外使用鲸鱼娘专属壁纸。

## 界面主题（浅色 / 深色）

顶栏「**主题**」按钮一键切换，深色是默认皮肤。主题覆盖顶栏、左侧任务栏、底部工具栏、右侧功能一览、全部二级页和设置里的标签页；选择只记在这台浏览器（`localStorage`），不写进 `settings.json`，也不影响角色与素材本身。

- **深色**：深蓝玻璃侧栏，夜间长时间看不刺眼。
- **浅色**：米白纸感侧栏，白天或亮屏下更清爽。

## 日记怎么翻

右侧「功能 → 看看日记」点开一篇后，长日记先折起一段预览，**点纸面或「展开日记」**再展开全文，读到底点「收起日记」折回去。展开状态在同一篇里会保持，翻到别的篇自动复位。点目录里的日记本封面则会打开全屏摊开的日记本，按左右页翻阅。

## 游戏模式（打游戏时省资源）

顶栏有「**游戏模式**」按钮，点一下进入低占用状态，再点「对话模式」恢复。快捷键 `Ctrl/⌘ + G`，设置 → 玩法里也有开关。状态存在浏览器本地，下次打开仍是上次的选择。

游戏模式只留下**静态立绘、场景背景、时钟、当前台词和切换按钮**，其余全部停掉：

- 停掉全部后台轮询（每 8 秒观察数据、每分钟场景/背景、每 2 分钟日程、天气、日记检查）；
- 停掉打字机逐字动画、CSS 呼吸/漂浮/闪烁动画、毛玻璃与阴影滤镜；
- 停掉 BGM、环境音、音效、自动朗读与语音合成；
- 停掉戳一戳、思考气泡、章节卡、转场特效，收起聊天输入与工具栏。

适合挂机打游戏：画面还在，但不让 GPU 反复合成动画，也不让 CPU 来回读文件。聊天、设置等功能退出游戏模式后照常用。

## 一、快速开始（三种方式，任选其一）

### 方式 A：独立桌面版（推荐，零依赖）

1. 到本仓库 [Releases 页面](https://github.com/Arco-Ai/qianfeiwanyu/releases/latest) 下载 `qianfeiwanyu-v1.0.6-win-x64.zip`（约 290 MB）。
2. 解压后进入 `千肥万鱼/` 文件夹，双击 `千肥万鱼.exe`。

不需要安装 Node.js、不需要浏览器、不需要 `npm install`。整个 `千肥万鱼` 文件夹可以拷到任何 Windows 电脑上直接用。

> 仓库源码本身不含打包产物（`.gitignore` 已忽略 `dist/`）；独立 exe 统一在 Releases 提供。想自己打包时，先 `npm install`，再执行 `node desktop/build-portable.js`。

### 方式 B：源码模式（需要 Node.js 18+）

在仓库根目录（包含 `server.js` 的那一层）执行：

```bash
node server.js
```

启动后控制台会打印**带访问令牌的地址**（形如 `http://127.0.0.1:18765/#fw_token=...`），**请用这个地址打开**；Windows 下 `start.cmd` 和直接 `node server.js` 都会自动帮你打开。令牌只存在你自己主目录的 `~/.fish-watch/api-token`，删掉后下次启动会重新生成。详见「访问令牌」一节。

> 源码模式的后端只用 Node 内置模块，**无需 npm install**。只有想自己打包 exe 时才需要 Electron（`npm install`）。

### 方式 C：作为 DSH 插件使用（可选联动）

仓库里的 `dsh-plugin/` 是一个标准的 DSH Bundle 插件 **`dsh-qianfeiwanyu`**。装进 DeepSeek Harness（DSH）后，她会**跟着 Agent 的工作状态实时换表情、说应景台词**——你写代码她在旁边认真盯着，你忙完她欢呼，你出错她被吓一跳。

| Agent 在做什么 | 她的反应 |
| --- | --- |
| 开始一轮 / 工具执行中 | 认真表情 + 「开始干活了」「调用工具 xxx」 |
| 收到新消息 / 等待 | 疑惑表情 + 「好像有新消息」 |
| 一轮完成 / 告一段落 | 欢呼表情 + 「这轮忙完了」 |
| 出错 | 受惊表情 + 「出错了」 |

**隐私与安全**：插件只监听 Agent 的**状态事件**，不读写会话内容、不联网；状态经 `127.0.0.1` 回环推给本机观察台。观察台开启「游戏模式」时会自动静默，不打扰你打游戏。

**三步上手**：

```bash
# 1. 先让「千肥万鱼」客户端保持运行（默认监听 127.0.0.1:18765）

# 2. 把插件装进 DSH（路径换成你 clone 后的实际位置），装完重启 DSH
dsh plugin --profile desktop add ./dsh-plugin

# 3. 观察台里打开开关：设置 → 对话 → DSH 插件联动
```

验证插件是否活着：浏览器访问 `http://127.0.0.1:3080/dsh-qianfeiwanyu/status`，看到 `{"ok":true,...}` 即正常。

完整说明（配置项、卸载、常见问题、状态调试）见 **[`dsh-plugin/README.md`](dsh-plugin/README.md)**。

## 二、换电脑 / 拷给别人

- **独立版**：把从 Releases 下载并解压后的 `千肥万鱼/` 文件夹整个拷过去即可。设置、素材、日程、日记都写在文件夹内部，跟着走。
- **源码版**：把整个仓库文件夹拷过去，有 Node 18+ 就能跑。
- 端口默认 `18765`。若被占用，桌面版会自动换一个端口；源码版可设环境变量 `FISH_WATCH_PORT=18766` 指定。

### 可选：连接别的电脑上的 DSH

打开「设置 → 对话」，把「DSH 地址」改成对方的移动桥地址，例如 `http://192.168.1.20:3080/m/api`，填好口令后点「测试连接」。

- DSH 会话是**默认**的聊天来源：消息直接投递到 DSH 的某个会话，回复从会话历史读回，走 DSH 链路、不消耗第三方 API 额度。
- 也可以设置环境变量 `DSH_ROOT` 指向 DSH 数据目录。

### 可选：第三方对话模型（DeepSeek 等）

聊天来源不再只有 DSH。在「设置 → 对话 → 来源」选「**第三方 API**」，即可直接接 DeepSeek 等 OpenAI 兼容的 `/chat/completions` 接口，不装 DSH 也能聊天：

- 填「接口地址」（默认 `https://api.deepseek.com/v1`）、「模型名」（默认 `deepseek-chat`）和 API Key，点「测试连接」。
- 密钥也可用环境变量 `FISH_CHAT_API_KEY` 提供；**密钥只保存在本机** `settings.json`，由服务端代为请求，浏览器不直接接触第三方、也不会把 Key 写进页面。
- 切到第三方后，对话由观察台自己保存，不会写进 DSH 会话；此时每次聊天会联网并消耗对应平台的 API 额度。
- 没装 DSH 也完全不影响运行：立绘、日程、互动照常工作，聊天改走上面的第三方接口即可。

### 可选：本地语音 GPT-SoVITS

- 没装也能正常用，只是不朗读（默认使用浏览器自带语音）。
- 装了的话会探测 `FISH_SOVITS_DIR`、程序目录下的 `GPT-SoVITS`、用户目录下的 `GPT-SoVITS` 三处（不再全盘扫描盘符）。
- **默认不自动启动**：启动脚本属于本机可执行文件，交给用户决定。在「设置 → 语音 → 本地 GPT-SoVITS」里点「启动本地 SoVITS」即可，按钮旁边会显示实际启动的脚本路径；想每次开机自动拉起，再勾上「自动启动」。

## 三、访问令牌（安全说明）

服务只监听 `127.0.0.1`，但**同一台机器上的其他账户、其他进程同样能连上这个端口**，所以除两个只读接口外，所有 `/api/` 都要求令牌：

| 接口 | 是否需要令牌 | 说明 |
| --- | --- | --- |
| `GET /api/health` | 否 | 只回答「端口上是不是千肥万鱼」，不含任何路径 |
| `GET/POST /api/dsh/agent-state` | 否 | DSH 插件读/推活动状态，只影响表情，不碰会话内容 |
| 其余所有 `/api/*` | **是** | 包括设置、聊天、日记、人格、素材包导入导出、外部 API 代理 |

- 令牌首次运行随机生成（24 字节），存放在 `~/.fish-watch/api-token`，权限 `0600`，只在当前用户可读。
- 桌面版由主进程把令牌放进页面地址的 `#fw_token=`（fragment 不会发给服务端，也不进日志），用户无感。
- 浏览器方式打开时，用控制台打印的带令牌地址；若直接开裸地址，页面会弹一次输入框。
- 想换令牌：关掉程序，删掉那个文件，再启动。
- **能挡什么**：同机其他账户、端口转发/反代暴露、盲目扫描的本机脚本。**挡不住什么**：已经以你的账户在跑的恶意程序——它能直接读令牌文件、读进程内存，这类风险只能靠系统层面防护。
- 素材文件（`/assets/*`）为了 `<img>` 能直接加载没有加令牌，属于已知取舍。

### 素材包导入的安全边界

- **先校验后写盘**：除了 manifest 格式、逐文件 CRC 与路径白名单，`assets.json` / `scenes.json` / `assets/audio/index.json` 还要通过结构校验；任何一项不合格整个包被拒绝，磁盘上一个字节都不改。
- **覆盖前先备份**：本次导入会覆盖的每一个文件（配置、图片、音频）都按原相对路径存到 `data/assetpack-backups/<时间戳-随机>/`，要恢复就把里面的文件拷回原位。
- **写入可回滚**：内容先写成同目录临时文件，再逐个改名落位；中途失败会把已落位的文件还原、清掉临时文件，不会留下新旧混杂的半成品。
- **读取有容错**：`assets.json` 即使被手工改坏（例如写成 `null`），素材接口仍按空配置返回，服务不会因此退出。

## 五、发布前请确认

分发给他人前，建议保持以下出厂状态（本仓库已处理好）：

- `settings.json` 中称呼、`portrait`、`dshSessionId`、API 密钥均为空。
- `chat-log.json` 为 `[]`（不含你的私人聊天记录）。
- 不含你的 DSH 会话 ID、SoVITS 参考音频路径等本机信息。
- 打包时 `data/`、`assets/uploads/` 与 `assets/audio/bgm/upload_*` **整目录 / 整类不复制**（不依赖扩展名清单，`.md` / `.txt` 人格备份也不会漏），随后只创建空目录骨架；`assets.json` 会清掉指向上传素材或不存在文件的槽位，`assets/audio/index.json` 会移除 `custom` 与 `upload_*` 条目。
- 打包在 `dist/千肥万鱼.building` 里完成，成功后才替换 `dist/千肥万鱼`；如果旧版已经被运行过、里面有聊天 / 日记 / 上传素材，会先把整个旧版改名成 `dist/千肥万鱼-备份-时间戳` 留档，绝不直接删除。结束前还会自检，发现运行数据、私人身份信息或失效素材引用就中止打包。

每位使用者第一次打开后，可在「设置」里填自己的称呼、DSH 地址和密钥。这些个人数据都保存在本地，不会上传。

## 六、常见问题

- **提示「选定的 DSH 会话已经不在列表里」？** 说明 DSH 里那个会话被删除、改名，或 DSH 重启后换了 id。打开对话面板顶部的会话下拉重新选一个即可；程序不会为了"能发出去"而自动改发到别的会话。
- **没有声音？** 打开「设置 → 音量」集中调整各类声音的开关与大小（语音、音乐/BGM、环境音、音效），拖动即时生效；BGM / 环境音 / 音效的开关也都在这同一页。也可以直接把鼠标移到右下工具栏的**喇叭图标**上，弹出的快捷音量条可随手调这四路音量。
- **想安静欣赏立绘和背景？** 点对话框右侧的小 **×** 进入「纯欣赏模式」——所有界面（顶栏、工具栏、对话框、任务栏、输入抽屉）全部隐藏，背景与立绘完整入镜。点右上角「退出欣赏」、按 `Esc`、或点画面空白处即可退出。
- **能换盘符 / 换用户名吗？** 可以。所有路径都相对程序目录解析，不写死任何电脑路径。
- **需要联网吗？** 默认不需要：立绘、日程、日记、互动、浏览器语音、BGM 与本地引擎都在本机完成。只有你主动启用外部能力时才会发起请求：聊天来源切到「第三方 API」（如 DeepSeek）后每次对话、点「生成立绘」、或用「服务端 TTS」朗读时（均需你先填好接口与密钥）。第三方对话会消耗对应平台的 API 额度。

## 七、素材署名

- **鲸鱼娘素材**：来自 [AATINF/deepseek-whale-girl-assets](https://github.com/AATINF/deepseek-whale-girl-assets)（二创扩展包，AI 生成），已抠成透明底 PNG 存于 `assets/whale/`（无损母版 WebP 备份在 `assets/whale-src/`，不随程序发布）。角色参考 [TreapGoGo/deepseek-whale-girl](https://github.com/TreapGoGo/deepseek-whale-girl)（MIT License, Copyright (c) 2026 TreapGoGo）。再分发请保留此署名，并如实标注使用了生成式 AI 辅助。
- **场景背景图**：`assets/bg/` 下 14 个场景 × 3 时段（白天 / 傍晚 / 夜晚）共 84 张背景图（自宅 / 学校 / 教室 / 上学路 / 街道 / 餐厅 / 神社 / 澡堂 / 医院 / 山里等），均为**生成式 AI 绘制**的二次元场景，已转为 JPG 并生成 `-t` 缩略图。每张由 AI 生成、无第三方版权素材；场景清单见 `scenes.json`。
- **背景音乐（BGM）**：`assets/audio/bgm/` 下 12 首音乐为**原创程序化合成**，不采样、不引用任何现有曲目旋律，可自由再分发。每首拥有独立的音色、节奏型、织体与和声语言，风格各异：
  - 清晨：晨光音乐盒（音乐盒 + 风铃）、晨露拨弦（拨弦 + 长笛）
  - 白天：晴天钢琴流行（柱式和弦 + 琶音 + 轻打击）、午后明亮拨弦（切分 + 马林巴）、日光竖琴琶音（十六分流动）
  - 黄昏：黄昏爵士（七和弦电钢 + walking bass + swing 刷镲）、晚霞弦乐（弦乐长音 + 稀疏钢琴）
  - 夜晚：夜空氛围（极简铺底 + 风铃 + 大混响）、月夜夜曲（低音分解 + 装饰旋律）
  - 其他：8-bit 俏皮（方波旋律 + 快节奏，菜单用）、温暖电钢（柔和七和弦 + 拨弦 + 长笛）、忧伤慢板（慢速钢琴 + 弦乐长音）
  
  生成脚本见仓库根目录 `gen_bgm.py`（`python gen_bgm.py --all --dir <目录>`），可在「设置 → 音乐选择」里试听并自选。
- **环境音 / 音效**：`assets/audio/amb/`、`assets/audio/sfx/` 由本地噪声合成，无第三方版权问题。
- **其他角色立绘**：未随本仓库提供；如需自行导入，请遵守对应原作者的授权，勿违规再分发。

## 八、仓库版（纯净模式）说明

本副本为**上传仓库专用**的纯净版本，与本地自用版的区别：

- **不含任何个人信息**：`settings.json` 为空白出厂模板（称呼、API Key、DSH 口令全空），`chat-log.json` 为 `[]`，无日记 / 日程 / 聊天记录 / 绝对路径 / 主机名。
- **不含运行数据**：`data/` 下各目录为空（保留 `.gitkeep`），由使用者运行时自行生成。
